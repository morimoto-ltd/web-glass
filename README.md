# Web Glass
This repository showcases content aware glass material packaged as a React component using SVG filters. Material supports extensive visual customizations which are applied in real time with no need to bake UV's, which makes it easily injectable in existing UIs. 

## Compatability
The material works well in Chrome, not so well in other browsers. There's an effort to make as much of it as possible work in other browsers, but it is very likely that Chrome is the only browser which will fully support it. Also frosted glass fallback is planned.

## Usage
The project is yet to be repackaged into a framework-agnostic library, until then you can clone the repository and import it directly.

## Contribution
Contributions are welcomed, especially ones improving portability of the material or adding docs.
